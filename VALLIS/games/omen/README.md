# OMEN Docs Pack (v1)

This is the Omen documentation + live tester shell, themed to match CoinFlip.

## What’s included
- `index.html` — full documentation page + live tester
- `omen.css` — includes CoinFlip base theme + Omen additions
- `omen.js` — includes CoinFlip controls/effects shell + Omen demo logic
- `assets/omen/glyphs/*` — transparent neon glyph exports at 512/256/128/64

## Notes
- This is a disclosed-odds UI tester. Production replaces the demo RNG with sealed seed + receipt verification.
- Anunnaki Vault is PRIVATE and not exposed in selectors.

Open `index.html` in a browser.
