Platform Entities

SENTINEL

Safety + correctness engine: throttles/pauses, distribution enforcement, exploit suppression, emergency controls.

SCAR

Continuity + statistics engine: drives the 3-layer multiplier framework (user + global + sealed monthly-average layer).

Daily Runes (Collectibles)

One rune per 24h (Outcome + SCAR + Vault). Duplicate protection: 1 respin excluding duplicate; if still duplicate → Rune Dust (cosmetic-only). Mythic/Hidden + Sentinel historic runes excluded by default.

Donation Perks

Cosmetic perks only (frames/effects/codex unlocks; optional non-stackable weekly cosmetic respin token). No odds/payout changes.

CONCLAVE

Non-binding voting hub for proposed features/games. Explicit disclaimer: votes inform direction but do not bind implementation.
