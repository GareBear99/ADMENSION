# Asset Variants (Ritual / Orbs)

This site supports TWO visual variants for each element (where applicable):
- Ritual variant
- Orbs variant

## Glyphs
Drop variant SVGs here:
- assets/glyphs/core/variants/ritual/<slug>.svg
- assets/glyphs/core/variants/orbs/<slug>.svg
- assets/glyphs/dice/variants/ritual/<slug>.svg
- assets/glyphs/dice/variants/orbs/<slug>.svg

The glyph pages will show buttons for Canonical / Ritual / Orbs.  
Missing files are detected and reported on the homepage.

## Runes & Relics
Reserved folders:
- assets/runes/variants/ritual/
- assets/runes/variants/orbs/
- assets/relics/variants/ritual/
- assets/relics/variants/orbs/

Once you add images here, we can wire Rune and Relic galleries the same way.
